🚩【③ コントローラーの修正】

編集時の画像アップロード処理を追加。

📂 app/Http/Controllers/ProjectController.php

updateメソッドを修正：


public function update(Request $request, Project $project)
{
    $validated = $request->validate([
        'active' => 'required|boolean',
        'project_name' => 'required|string|max:255',
        'segment_id' => 'required|exists:segments,id',
        'base_id' => 'required|exists:bases,id',
        'ssid_id' => 'required|exists:ssids,id',
        'note' => 'nullable|string|max:1024',
        'manager_emp_no' => 'required|string|max:255',
        'manager_name' => 'required|string|max:255',
        'it_manager_emp_no' => 'required|string|max:255',
        'it_manager_name' => 'required|string|max:255',
        'start_date' => 'required|date',
        'end_date' => 'nullable|date|after:start_date',
        'image' => 'nullable|image|max:2048', // 画像のバリデーション
    ]);

    // 画像の処理
    if ($request->hasFile('image')) {
        $path = $request->file('image')->store('project_images', 'public');
        $validated['image_path'] = $path;
    }

    $project->update($validated);

    return redirect()->route('projects.show', $project)->with('success', 'プロジェクトを更新しました。');
}

🚩【⑥ ストレージ設定（重要）】

Laravelで画像を公開するために、ストレージのリンクを作成します。

php artisan storage:link

これにより以下が作成されます：

public/storage -> storage/app/public


---

🚩【⑦ config/filesystems.phpの確認（推奨設定）】

storage/app/publicへの保存がデフォルトで設定済みのため、変更は不要です。


---

🚩【動作確認手順】

1. 編集画面から画像ファイルを選択し保存


2. プロジェクト詳細ページに画像が表示されることを確認




---

🚩【注意事項と補足】

アップロードする画像サイズを2MBまでに制限しています。
（サイズ変更したい場合はmax:2048の値を調整してください）

画像の保存先：storage/app/public/project_images

画像の表示方法：asset('storage/'.$project->image_path)
